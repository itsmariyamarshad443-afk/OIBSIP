# Unemployment Analysis with Python

## Oasis Infobyte Data Science Internship

### Task 2: Unemployment Analysis with Python

## Objective

The objective of this project is to analyze unemployment trends in India using data analysis and visualization techniques. The project examines regional differences, changes over time, and the impact of the COVID-19 period on unemployment.

## Dataset

The project uses the Unemployment in India dataset.

The dataset contains information related to:

* Region
* Date
* Frequency
* Estimated Unemployment Rate (%)
* Estimated Employed
* Estimated Labour Participation Rate (%)
* Area

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Steps

1. Load the dataset
2. Inspect the dataset structure
3. Clean column names
4. Check missing values
5. Convert the date column
6. Remove or handle missing records
7. Analyze average unemployment by region
8. Analyze unemployment trends over time
9. Compare unemployment trends for selected regions
10. Identify regions with higher unemployment rates
11. Create a correlation heatmap
12. Compare pre-COVID and post-COVID unemployment
13. Visualize important findings
14. Write observations based on the analysis

## Visualizations

The project includes:

* Regional unemployment analysis
* Time-series analysis
* Three-region comparison
* Top 10 regions bar chart
* Correlation heatmap
* Pre-COVID vs Post-COVID comparison

## Key Analysis

The analysis focuses on understanding how unemployment varies across regions and over time. It also examines the relationship between unemployment, employment, and labour participation.

## Results

The results are based on the actual calculations and visualizations produced in the notebook. The analysis highlights regional and temporal differences in unemployment and compares unemployment levels before and after the COVID-19 period.

## Conclusion

This project demonstrates how Python-based data analysis and visualization can be used to understand unemployment patterns and extract meaningful insights from real-world data.
