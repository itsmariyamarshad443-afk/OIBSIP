# Iris Flower Classification

## Oasis Infobyte Data Science Internship

### Task 1: Iris Flower Classification

## Objective

The objective of this project is to build a machine learning classification model to classify Iris flowers into different species based on their measurements. The project includes data analysis, visualization, model training, evaluation, and comparison of different classification algorithms.

## Dataset

The project uses the Iris dataset available through the Scikit-learn library.

The dataset contains information related to:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species

The three target species are:

* Setosa
* Versicolor
* Virginica

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Steps

1. Load the Iris dataset
2. Create a DataFrame
3. Inspect the dataset structure
4. Check dataset shape
5. Check data types
6. Check missing values
7. Generate descriptive statistics
8. Analyze species distribution
9. Create a pairplot
10. Create box plots for the features
11. Analyze the most discriminative features
12. Split the dataset into training and testing sets
13. Train a Logistic Regression model
14. Train a K-Nearest Neighbors (KNN) model
15. Evaluate both models
16. Create confusion matrices
17. Compare model accuracy
18. Identify the best-performing model
19. Write observations and conclusion

## Visualizations

The project includes:

* Species distribution chart
* Pairplot showing feature relationships
* Box plots for Iris features
* Logistic Regression confusion matrix
* KNN confusion matrix
* Model accuracy comparison chart

## Key Analysis

The analysis focuses on understanding the relationships between the four Iris flower measurements and the three species.

The visualizations are used to identify which features provide better separation between the different Iris species.

Petal length and petal width show strong differences between the species and are particularly useful for classification.

## Machine Learning Models

Two classification algorithms are implemented:

* Logistic Regression
* K-Nearest Neighbors (KNN)

The dataset is divided into training and testing data, with 80% used for training and 20% used for testing.

## Model Evaluation

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

The accuracy of both models is compared to identify the best-performing model.

## Results

The results are based on the actual calculations and visualizations produced in the notebook. The analysis shows the performance of Logistic Regression and K-Nearest Neighbors in classifying the three Iris flower species.

The model with the higher accuracy is selected as the best-performing model.

## Conclusion

This project demonstrates how Python and machine learning techniques can be used to analyze the Iris dataset and classify flowers into different species.

Exploratory data analysis and visualization were used to understand the dataset and identify important features. Two classification models were then trained, evaluated, and compared to determine the better-performing model.
