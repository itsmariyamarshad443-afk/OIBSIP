# Sales Prediction Using Python

## Oasis Infobyte Data Science Internship

### Task 5: Sales Prediction Using Python

## Objective

The objective of this project is to predict product sales based on advertising expenditure through different marketing channels.

The project analyzes the relationship between advertising spending on TV, Radio, and Newspaper and the resulting sales.

## Dataset

The project uses the Advertising dataset.

The main features are:

* TV
* Radio
* Newspaper

The target variable is:

* Sales

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Steps

1. Load the advertising dataset
2. Explore the dataset
3. Check data types and missing values
4. Generate descriptive statistics
5. Perform Exploratory Data Analysis
6. Create pairplots
7. Analyze relationships between advertising channels and sales
8. Create a correlation heatmap
9. Split the data into training and testing sets
10. Train Linear Regression
11. Train Random Forest Regression
12. Evaluate both models
13. Compare model performance
14. Perform residual analysis
15. Analyze feature importance
16. Identify the most influential advertising channel

## Machine Learning Models

### Linear Regression

Linear Regression is used to model the relationship between advertising expenditure and sales.

### Random Forest Regressor

Random Forest Regression is used to model the relationship between the advertising features and sales using an ensemble of decision trees.

## Evaluation Metrics

The models are evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

For MAE and RMSE, lower values indicate better performance. For R², a higher value indicates better performance.

## Visualizations

The project includes:

* Pairplot
* TV vs Sales scatter plot
* Radio vs Sales scatter plot
* Newspaper vs Sales scatter plot
* Correlation heatmap
* Actual vs Predicted Sales plot
* Residual plot
* Feature importance chart

## Results

The performance of Linear Regression and Random Forest Regression is compared using MAE, RMSE, and R². Feature importance is also analyzed to identify the advertising channel with the greatest influence on sales predictions.

## Conclusion

This project demonstrates how machine learning and data analysis can be used to predict sales from advertising expenditure and identify important marketing channels.
